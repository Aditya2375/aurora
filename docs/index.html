Aurora - an x86 OS booting in your browser

A real BIOS-bootable kernel in C and assembly: protected mode, write-protected paging, a checked allocator, a RAM filesystem and a shell. The disk image below is the one the Makefile builds, running in the v86 emulator. Source on GitHub.

Click the screen to type, or use the buttons. Try mkdir demo, write demo/hi.txt hello, cat demo/hi.txt, then write /sys/x y to see the read-only system area refuse.

Hardened

  • Read-only code, null page, stack guard
  • Bounded input, paths and files
  • Fail-closed bootloader memory map

Not provided

  • User processes, ring 3, NX, ASLR
  • Network, accounts, disk persistence
  • Everything runs in ring 0

Tested

  • Host suite, ASan/UBSan, fuzzing
  • Real loader assembly vs bad BIOS data
  • QEMU boots at 16 to 256 MiB

Files live in emulated RAM and disappear on reboot. Nothing you type leaves your browser. Built with v86 (BSD-2-Clause) and SeaBIOS (LGPL); see firmware licenses. MIT licensed.
