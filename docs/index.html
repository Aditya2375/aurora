aurora - an x86 operating system

The real thing: aurora's boot sector, protected-mode loader and kernel, built into the same boot image the repo's Makefile produces, booting here in an x86 PC emulator (v86) running as WebAssembly. Nothing is simulated at the OS level - every byte on screen came out of the kernel's own VGA driver. Source on GitHub.

Click the screen, then type. Try: help, mem, uptime, clear. The keyboard is captured only while the screen has focus.
